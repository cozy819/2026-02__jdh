숫자 다섯 개와 그림 한 장五个数字和一张图

이런 장면这样的场景

뉴스에서 “물가가 크게 올랐다”며 그래프를 보여 줍니다. 막대가 가파르게 치솟아 있어 한눈에 심각해 보입니다.新闻里说“物价大涨”，并放出一张图。柱子陡然拔高，一眼看去很严重。

그런데 자세히 보니 세로축이 0이 아니라 98에서 시작합니다. 실제 값은 100에서 103으로, 3만큼 올랐을 뿐입니다. 축을 0부터 그렸다면 거의 평평한 그래프가 됩니다.可仔细一看，纵轴不是从 0 开始，而是从 98 开始。实际数值从 100 变成 103，只涨了 3。要是把轴从 0 画起，这张图几乎是平的。

데이터를 조작한 것은 아닙니다. 숫자는 전부 사실입니다. 그런데도 보는 사람은 다른 인상을 받습니다. 그래프는 어떻게 이런 일을 할 수 있을까요?数据并没有被篡改。数字全是真的。可看的人得到的印象却不一样。图表怎么能做到这一点呢？

핵심 질문核心问题

여러 개의 숫자를 표와 그래프로 바꾸면 무엇을 더 쉽게 알 수 있으며,
무엇을 조심해야 할까?把一堆数字变成表格和图表，能更容易看出什么，
又要当心什么？

앞 차시에서 가져올 것从上一课时带过来的
  • 3-2에서 [40, 75, 20, 90]을 숫자로 읽었다. 합계 225, 목표 달성 2일.3-2 里我们把 [40, 75, 20, 90] 当数字读过。合计 225，达标 2 天。
  • 2-1에서 라이브러리는 “다른 사람이 만들어 공개한 기능 묶음”이라고 배웠다. 그때 이름만 본 pandas와 Matplotlib이 오늘 등장한다.2-1 学过库是“别人做好并公开的功能包”。当时只看了名字的 pandas 和 Matplotlib，今天登场。
  • 2-2에서 uv add pandas matplotlib으로 이 두 라이브러리를 이미 설치해 두었다.2-2 里用 uv add pandas matplotlib 已经装好了这两个库。

3-2에서 구한 “합계 225분”이라는 답을 떠올려 보세요. 정확한 값입니다. 그런데 그 한 줄만 보고 어느 날이 유독 적었는지, 들쭉날쭉한 편인지를 알 수 있었나요? 요약된 숫자 하나는 언제나 무언가를 버립니다. 이번 차시는 거기서 출발합니다.回想 3-2 求出的“合计 225 分钟”。这个值是准确的。可光看这一行，你能知道哪一天特别少、波动大不大吗？一个被压缩出来的数字，总会丢掉些什么。这一课时就从这里出发。

데이터data数据data
현상现象
친구가 문자로 “35”라고만 보냈습니다. 무슨 뜻인지 알 수 없습니다. 기온일까, 몇 분일까, 몇 명일까.朋友发来短信，只写了 “35”。不知道什么意思。是气温、是几分钟，还是几个人？
쉬운 설명通俗说法
어떤 대상을 관찰하거나 측정해서 기록해 둔 값입니다.它是观察或测量某个对象后记录下来的值。
정확한 정의准确定义
관찰·측정·수집을 통해 기록한 값의 모음. 그 자체로는 해석되지 않은 상태다.通过观察、测量、收集而记录下来的值的集合。它本身尚未被解释。
경계边界
1-1에서 데이터는 해석되지 않은 값, 정보는 해석되어 판단 근거가 된 것이라고 했습니다. 오늘 하는 일이 바로 데이터를 정보로 바꾸는 작업입니다.1-1 说过，数据是未被解释的值，信息是被解释后成为判断依据的东西。今天做的正是把数据变成信息的工作。
문장 속 사용例句
“이 데이터는 단위가 없어서 아직 해석할 수 없다.”“这份数据没有单位，还没法解读。”

데이터는 그 자체로 완전한 설명이 아닙니다. 35라는 숫자만 보면 온도인지, 인원인지, 시간인지 알 수 없습니다. 무엇을 측정했는지, 단위가 무엇인지, 언제 어떤 방법으로 모았는지 같은 맥락(context)이 함께 있어야 의미를 해석할 수 있습니다.数据本身不是完整的说明。只看 35 这个数字，不知道是温度、人数还是时间。必须连同背景（context）——测的是什么、单位是什么、何时用什么方法收集的——一起，才能解读其含义。

2. 라이브러리2. 库4-1

이미 만들어진 기능을 빌려 쓴다借用已经做好的功能 핵심核心

Python의 기본 문법만으로도 합계는 구할 수 있습니다. 3-2에서 직접 해 봤습니다. 그러나 표를 정리하고 그래프를 그리는 기능까지 처음부터 만들 필요는 없습니다.光靠 Python 的基本语法也能求合计，3-2 里我们亲手做过。但整理表格、乃至画图表的功能，没必要从头造。

2-1에서 배운 라이브러리를 드디어 실제로 씁니다. 특정 작업에 필요한 코드와 기능을 모아 다른 프로그램에서 쓸 수 있게 만든 것입니다.2-1 学过的库，终于要真正用上了。它是把某项工作所需的代码与功能收拢起来、供别的程序使用的东西。

라이브러리库역할职责
pandas표 형태의 데이터를 읽고, 고르고, 계산하고 정리한다.读取、筛选、计算并整理表格形式的数据。
matplotlib데이터를 여러 종류의 그래프로 표현한다.把数据表现成各种类型的图表。

라이브러리를 쓰려면 두 가지가 필요합니다. 먼저 실행 환경에 설치되어 있어야 하고, 코드에서는 import로 불러와야 합니다.要用库，需要两件事：先得安装在运行环境里，然后在代码中用 import 引入。

라이브러리 불러오기引入库
import pandas as pd
import matplotlib.pyplot as plt

as pd와 as plt는 긴 이름을 코드에서 짧게 쓰기 위한 별명입니다. pd는 새로운 라이브러리가 아니라 pandas를 부르는 다른 이름일 뿐입니다. 관습적으로 거의 모든 코드가 이 두 별명을 쓰므로, AI가 만든 코드에서도 그대로 보게 됩니다.as pd 和 as plt 是为了在代码里把长名字写短的别名。pd 不是新的库，只是 pandas 的另一个叫法。几乎所有代码都习惯用这两个别名，所以在 AI 写的代码里也会照样看到。

설치는 이미 끝나 있습니다安装已经完成了

2-2에서 uv add pandas matplotlib을 실행했던 것을 기억하나요? 그때 이 두 라이브러리가 프로젝트의 .venv에 들어갔습니다. 그래서 오늘은 import만 하면 됩니다.还记得 2-2 里执行过 uv add pandas matplotlib 吗？那时这两个库就进了项目的 .venv。所以今天只要 import 就行。

만약 ModuleNotFoundError가 난다면 커널이 .venv가 아닌 다른 Python을 가리키고 있을 가능성이 큽니다. 2-2의 “세 곳이 같은 .venv를 가리켜야 한다”로 돌아가세요.如果报 ModuleNotFoundError，很可能是内核指向了 .venv 以外的另一个 Python。请回到 2-2 的“三处必须指向同一个 .venv”。

“pandas를 불러왔는데 왜 데이터가 없죠?”“我引入了 pandas，怎么没有数据？”

당연합니다. import는 도구를 꺼낸 것이지 데이터를 가져온 것이 아닙니다. CSV 파일이나 표는 따로 읽거나 만들어야 합니다.这是当然的。import 是把工具拿出来，不是把数据取来。CSV 文件或表格要另外读取或创建。

2-1에서 “VS Code에 Python 확장을 설치했다고 Python 자체가 생기는 것은 아니다”라고 했던 것과 같은 종류의 구분입니다. 준비하는 일과 실제 대상을 가져오는 일은 다릅니다.这和 2-1 说的“在 VS Code 装了 Python 扩展，不等于就有了 Python 本身”是同一类区分。做准备和把实际对象取来，是两回事。

3. pandas3. pandas4-1

표 데이터를 다루는 도구处理表格数据的工具 핵심核心

pandas는 Python에서 표 형태의 데이터를 다루기 위해 쓰는 라이브러리입니다. 엑셀이나 스프레드시트의 표처럼 행과 열로 정리된 데이터를 불러오고, 필요한 부분을 고르고, 계산하고, 정리할 수 있습니다.pandas 是在 Python 中处理表格形式数据所用的库。像 Excel 或电子表格那样按行列整理的数据，它都能读进来、挑出需要的部分、进行计算和整理。

pandas로 할 수 있는 일用 pandas 能做的事

  • CSV 파일과 같은 표 데이터를 불러온다.读取 CSV 之类的表格数据。
  • 행과 열의 개수와 이름을 확인한다.确认行和列的数量与名称。
  • 필요한 행이나 열을 선택한다.选出需要的行或列。
  • 합계, 평균, 최솟값과 최댓값을 계산한다.计算合计、平均、最小值与最大值。
  • 빠진 값이나 이상한 값을 확인한다.检查是否有缺失值或异常值。
  • 그래프를 그릴 수 있도록 데이터를 정리한다.把数据整理成可以绘图的样子。

3-2에서 우리가 for 반복문으로 한 줄씩 쌓아 만들었던 합계 같은 계산을, pandas는 물론 평균·최솟값·최댓값까지 한 줄로 해 줍니다. 그렇다고 3-2가 헛수고였던 것은 아닙니다. 안에서 무슨 일이 일어나는지 아는 사람과 결과만 받아 보는 사람은 같은 한 줄을 봐도 다르게 읽습니다.3-2 里我们用 for 循环一行行累出来的合计，pandas 连同平均、最小值、最大值一起，一行就搞定。但这不代表 3-2 白做了。知道里面在发生什么的人和只接收结果的人，看同样一行代码，读出来的东西不一样。

pandas는 데이터를 해석해 주지 않는다pandas 不会替你解读数据

계산과 정리는 빠르게 해 줍니다. 그러나 어떤 데이터와 열을 사용할지, 그 결과가 무엇을 뜻하는지는 사람이 판단해야 합니다.它把计算和整理做得很快。但用哪份数据、哪些列，以及结果意味着什么，得由人来判断。

이 수업에서 계속 반복해 온 문장이 여기서도 그대로입니다. 도구는 빨라지지만 목적을 정하고 결과를 판단하는 자리는 사람에게 남습니다.这门课反复出现的那句话在这里同样成立：工具变快了，定目标、判断结果的位置仍然留给人。

3. pandas3. pandas4-1

이번 학기의 사용 범위本学期的使用范围

쉬운 설명通俗说法
pandas가 데이터를 담아 두는 표입니다. 행과 열이 있고 열마다 이름이 붙어 있습니다.它是 pandas 用来装数据的表。有行有列，每列都带着名字。
정확한 정의准确定义
pandas에서 행과 열로 구성된 2차원 표 형태의 자료구조. 각 열은 이름을 가지며 서로 다른 자료형을 담을 수 있다.pandas 中由行与列构成的二维表状数据结构。每列拥有名称，且各列可容纳不同的数据类型。
경계边界
pandas는 도구(라이브러리)이고 DataFrame은 그 도구가 다루는 표입니다. 3-2의 리스트·딕셔너리처럼 자료구조의 한 종류라고 보면 됩니다.pandas 是工具（库），DataFrame 是这个工具所处理的表。可以把它看成像 3-2 的列表、字典那样的一种数据结构。
문장 속 사용例句
“CSV를 읽었더니 5행 2열짜리 DataFrame이 만들어졌다.”“读了 CSV，生成了一个 5 行 2 列的 DataFrame。”
DataFrame 만들기创建 DataFrame
data = pd.DataFrame({
    "day": ["Mon", "Tue", "Wed", "Thu", "Fri"],
    "reading_minutes": [40, 55, 30, 70, 45],
})

3-2에서 배운 것들이 그대로 보입니다. 바깥의 { }는 딕셔너리이고, 안의 [ ]는 리스트입니다. 딕셔너리의 키가 열 이름이 되고, 각 리스트의 값이 그 열의 데이터가 됩니다.3-2 学的东西在这里原样可见。外面的 { } 是字典，里面的 [ ] 是列表。字典的键成为列名，各列表里的值成为该列的数据。

그래프는 질문에 맞게 고른다图表按问题来选

알고 싶은 것想知道什么알맞은 그래프合适的图表예例
여러 항목의 크기 비교多个项目的大小比较막대그래프柱状图요일별 이용 인원 비교比较各星期的使用人数

그래프마다 알맞은 쓰임이 다르다每种图表都有适合的用途

같은 데이터로도 여러 그래프를 그릴 수 있습니다. 무엇을 고를지는 내가 무엇을 알고 싶은가에 달려 있습니다. 요일별 인원을 비교하고 싶으면 막대, 변화를 보고 싶으면 선입니다.同一份数据可以画出多种图。选哪一种，取决于我想知道什么。想比较各星期的人数就用柱状图，想看变化就用折线图。

그래프가 화려하다고 좋은 것이 아닙니다. 그래프마다 알맞은 쓰임이 다르며, 제목·축·단위·출처를 읽는 사람이 확인할 수 있어야 합니다.图表华丽并不等于好。每种图表都有适合的用途，读的人还应能确认标题、坐标轴、单位与出处。

수행평가의 그래프 종류와 조건은 교사가 지정하며, 학생은 AI 결과가 조건과 맞는지 확인합니다.实作评价的图表类型和条件由老师指定，学生核对 AI 结果是否符合条件。

6. 그래프의 한계6. 图表的局限4-1

그래프는 사실을 자동으로 설명하지 않는다图表不会自动解释事实 핵심核心

그래프는 데이터를 요약하지만 원인까지 증명하지는 않습니다. 두 값이 함께 늘었다고 해서 한쪽이 다른 쪽의 원인이라고 바로 말할 수 없습니다.图表摘要数据，但并不证明原因。两个数值一起上升，并不能马上说其中一个是另一个的原因。

그래프로 말할 수 있는 것能凭图表说的
  • “목요일이 32명으로 가장 많다.”“星期四 32 人，最多。”
  • “월요일과 목요일의 차이는 14명이다.”“星期一和星期四相差 14 人。”
  • “화요일 이후 계속 늘었다가 금요일에 줄었다.”“星期二之后一路上升，星期五下降。”

모두 그래프에서 직접 읽을 수 있는 값과 비교입니다.全都是能从图上直接读出的数值与比较。

말할 수 없는 것不能说的
  • “목요일에 행사가 있어서 많았다.”“星期四因为有活动所以人多。”
  • “시험 기간이라 도서관을 많이 썼다.”“考试期间所以图书馆用得多。”
  • “이대로 가면 다음 주엔 40명이 될 것이다.”“照这样下去下周会到 40 人。”

모두 데이터에 들어 있지 않은 원인과 예측입니다.全都是数据里没有的原因与预测。

오른쪽 문장들이 틀렸다는 뜻은 아닙니다. 실제로 그럴 수도 있습니다. 문제는 이 데이터만으로는 알 수 없다는 점입니다. 원인을 말하려면 다른 근거가 더 필요합니다.右边那些句子并不是说错了。实际情况可能真是那样。问题在于光凭这份数据无法知道。要说原因，还需要别的依据。

정직하게 쓰는 법诚实的写法

원인이 궁금하다면 이렇게 씁니다. “목요일이 가장 많았다. 그 이유는 이 데이터만으로는 알 수 없다. 행사 일정이나 시험 기간 자료를 함께 봐야 확인할 수 있다.”想知道原因就这样写：“星期四最多。其原因仅凭这份数据无法得知。需要一并查看活动安排或考试日程等资料才能确认。”

모른다고 적는 것은 부족한 답이 아니라 정확한 답입니다. 1-1에서 “이해하지 못한 부분을 적는 편이 낫다”고 약속했던 것과 같은 태도입니다.写下“不知道”不是不足的答案，而是准确的答案。这和 1-1 约定的“不如写上自己没理解的部分”是同一种态度。

8. AI 검토8. 检查 AI 的结果4-1

AI가 만든 그래프를 검토하는 일곱 질문检查 AI 所作图表的七个问题 핵심核心

AI에게 데이터와 그래프 코드를 요청했다면 다음을 확인합니다. 다음 차시 실습에서 실제로 쓸 목록입니다.若向 AI 要了数据和绘图代码，就确认以下各项。这是下一课时实践中真要用的清单。

그래프 검토 목록图表检查清单
  1. 사용한 데이터가 원본과 같은가? — 값 하나라도 달라지지 않았는가用的数据和原始数据一样吗？ — 有没有哪怕一个值变了
  2. 행과 열을 올바르게 선택했는가? — 엉뚱한 열을 그리지 않았는가行和列选对了吗？ — 有没有画错了列
  3. 교사가 요구한 그래프 종류인가? — 지정된 종류와 다른 그래프를 쓰지 않았는가是老师指定的图表类型吗？ — 是否用了不同于要求的图表
  4. 제목, 축 이름과 단위가 있는가?有标题、轴名和单位吗？
  5. 축의 범위가 차이를 과장하거나 숨기지 않는가?坐标轴范围有没有夸大或掩盖差异？
  6. 그래프에서 확인한 값 한 가지가 원본과 일치하는가?从图中确认的一项数值与原始数据一致吗？
  7. 실제 데이터라면 출처와 수집 시점을 기록했는가?若是真实数据，有没有记录出处与采集时间？
AI가 코드를 정확히 써도 그래프가 틀릴 수 있다AI 代码写得再准，图也可能是错的

AI가 문법적으로 완벽한 코드를 만들었더라도, 사용자가 잘못된 열을 지정하거나 질문을 잘못 정하면 의미 없는 그래프가 나옵니다.即便 AI 写出了语法上完美的代码，若使用者指定了错误的列或把问题问错了，出来的也是没有意义的图。

예를 들어 “요일별 이용 인원 비교”를 원하면서 요일이 아닌 번호 열을 가로축으로 지정하면, 코드는 완벽히 실행되고 그래프도 예쁘게 그려지지만 아무 뜻이 없습니다.比如想要“比较各星期的使用人数”，却把横轴指定成了不是星期的编号列，那么代码运行得完美、图也画得漂亮，却毫无意义。

3-2에서 배운 논리 오류가 그래프에서 나타나는 모습입니다. 오류 메시지는 나오지 않습니다.这就是 3-2 学过的逻辑错误出现在图表上的样子。不会有任何报错信息。

9. 오개념 점검9. 误区检查4-1

흔한 오해와 잘못된 설명常见的误解与错误说法

오해误解
“import pandas를 하면 데이터가 준비된다.”“执行 import pandas 数据就准备好了。”
사실事实
import는 기능(도구)을 꺼낸 것일 뿐입니다. 표나 CSV는 따로 만들거나 읽어야 합니다. 도구를 꺼낸 것과 재료를 가져온 것은 다릅니다.import 只是把功能（工具）拿出来。表格或 CSV 要另外创建或读取。拿出工具和取来材料，不是一回事。
오해误解
“pandas는 데이터를 분석해 준다.”“pandas 会替我分析数据。”
사실事实
pandas는 계산과 정리를 빠르게 해 줍니다. 어떤 열을 쓸지, 결과가 무엇을 뜻하는지는 사람이 판단합니다. 도구는 답을 계산하지 질문을 만들지 않습니다.pandas 把计算和整理做得很快。用哪些列、结果意味着什么，由人判断。工具计算答案，但不提出问题。
오해误解
“그래프 종류는 데이터의 종류가 정한다.”“图表类型由数据的种类决定。”
사실事实
답하려는 질문이 정합니다. 같은 데이터로도 비교를 보려면 막대, 시간의 변화를 보려면 선을 씁니다.由要回答的问题决定。同样的数据，想看比较就用柱状图，想看随时间的变化就用折线图。
오해误解
“두 값이 함께 늘었으니 하나가 다른 하나의 원인이다.”“两个值一起涨了，所以一个是另一个的原因。”
사실事实
그래프는 함께 움직였다는 사실까지만 보여 줍니다. 원인을 말하려면 다른 근거가 더 필요합니다. 우연히 같이 움직이는 값도 많습니다.图表只能说明它们一起动了。要说原因还需要别的依据。偶然一起动的数值也很多。
9. 오개념 점검9. 误区检查4-1

흔한 오해와 잘못된 설명常见的误解与错误说法(이어서)（续）

오해误解
“그래프가 예쁘고 화려하면 좋은 그래프다.”“图画得漂亮华丽就是好图。”
사실事实
좋은 그래프는 질문에 맞고 오해 없이 읽히는 그래프입니다. 색과 장식이 많으면 오히려 중요한 차이가 가려집니다.好图是切合问题、读起来不会产生误解的图。颜色和装饰太多，反而遮住了重要的差异。
오해误解
“코드가 오류 없이 그래프를 그렸으니 맞는 그래프다.”“代码没报错就把图画出来了，那就是对的图。”
사실事实
엉뚱한 열을 지정해도 그래프는 예쁘게 그려집니다. 원본 표와 그래프를 하나씩 대조해야 확인됩니다.就算指定了错的列，图照样画得漂亮。必须把原始表格和图逐项对照才能确认。

라이브러리는 데이터를 처리하는 기능의 묶음이고, 데이터는 관찰하거나 기록한 값입니다. import pandas는 도구를 꺼낸 것이고, 표를 만들거나 CSV를 읽는 것은 재료를 가져오는 것입니다.库是处理数据的功能包，数据是观察或记录下来的值。import pandas 是把工具拿出来，而建表或读 CSV 才是把材料取来。

11. 정리11. 小结4-1

핵심 정리核心小结

이번 차시에서 남길 것本课时要记住的
  • 데이터는 맥락과 단위를 함께 알아야 해석할 수 있다. 열 이름에 단위를 넣으면 표만 봐도 전달된다.数据必须连同背景与单位一起知道才能解读。把单位写进列名，光看表就传达到了。
  • pandas는 표 데이터를 다루고 Matplotlib은 그래프를 그리는 라이브러리다.pandas 处理表格数据，Matplotlib 是画图表的库。
  • import는 기능을 꺼낸 것이고, 데이터는 따로 만들거나 읽어야 한다.import 是把功能拿出来，数据要另外创建或读取。
  • DataFrame은 pandas가 다루는 행과 열의 표다. 딕셔너리의 키가 열 이름이 된다.DataFrame 是 pandas 处理的行列之表。字典的键成为列名。
  • 그래프 종류마다 알맞은 쓰임이 있으며 수행평가에서는 교사가 지정한 종류를 사용한다.每种图表都有适合的用途，实作评价中使用老师指定的类型。
  • 그래프는 원인을 증명하지 않는다. 말할 수 있는 사실과 없는 원인을 구분한다.图表不证明原因。要区分能说的事实与不能说的原因。
  • 축의 시작점, 기간 선택, 단위와 출처, 장식, 빠진 값이 인상을 바꿀 수 있다.轴的起点、时间段的挑选、单位与出处、装饰、缺失值，都可能改变印象。
  • “코드가 실행되었는가”에 더해 “정직하게 보여 주는가”를 묻는다.除了“代码跑起来了吗”，还要问“展示得诚实吗”。
