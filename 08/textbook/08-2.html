OpenCode가 key를 못 찾으면 브라우저로 다시 연결한다OpenCode 找不到 key 时，用浏览器重新连接 필요할 때需要时

2-1에서 OpenCode Zen에서 API 키를 만들어 /connect에 붙여 넣었습니다. 그 뒤 OpenCode Zen이 OpenCode Console로 합쳐지면서, 예전 키가 남아 있으면 「key를 찾을 수 없다」는 오류가 날 수 있습니다. 이때는 키를 다시 붙여 넣어도 되지 않습니다. 예전 연결을 지우고 브라우저 로그인으로 다시 연결합니다.2-1 在 OpenCode Zen 生成 API 密钥，粘贴到 /connect 里。后来 OpenCode Zen 并入了 OpenCode Console，如果还留着以前的密钥，就可能出现“找不到 key”的错误。这时重新粘贴密钥也没用。要删掉以前的连接，用浏览器登录重新连接。

순서顺序
  1. OpenCode 입력칸에 /exit를 입력해 닫는다.在 OpenCode 输入框里输入 /exit 关掉它。
  2. 같은 터미널에 opencode auth logout을 입력한다. Select integration 목록에서 이름에 OpenCode가 들어간 연결(예: OpenCode Console)을 고르고 Enter를 누른다.在同一个终端里输入 opencode auth logout。在 Select integration 列表里选名字带 OpenCode 的连接（例：OpenCode Console），按 Enter。
  3. 다시 opencode를 입력해 켜고, 입력칸에 /connect를 입력한다.再输入 opencode 打开，在输入框里输入 /connect。
  4. OpenCode Console을 고르면 브라우저가 열린다. 키를 넣는 칸이 아니라 로그인 화면이다. 2-1에서 쓴 계정으로 로그인한다.选 OpenCode Console 后会打开浏览器。这里不是输入密钥的框，而是登录画面。用 2-1 用过的账号登录。
  5. 로그인이 끝나면 터미널로 돌아와 모델을 고르고, 막혔던 요청을 다시 보낸다.登录完成后回到终端选好模型，把刚才卡住的请求再发一次。
키를 다시 복사해 넣는 것으로는 고쳐지지 않습니다重新复制粘贴密钥解决不了

새 키를 만들어 붙여 넣어도 같은 오류가 납니다. 꼭 opencode auth logout으로 예전 연결을 먼저 지웁니다. 다시 연결한 뒤에도 06 폴더의 AGENTS.md와 AI대화기록.md는 그대로 남아 있으니, 시작 요청문을 다시 보낼 필요는 없습니다.生成新密钥粘贴进去，也会出现同样的错误。一定要先用 opencode auth logout 删掉以前的连接。重新连接后，06 文件夹里的 AGENTS.md 和 AI대화기록.md 都还在，不需要重发开始请求。
