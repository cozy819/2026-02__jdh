3. 세 흐름3. 三条流程13-2

다시 켠 뒤의 기록을 SQLite Viewer에서도 확인한다重新启动后的记录，也在 SQLite Viewer 里确认 (이어서)（续）

다시 켠 화면에 기록이 보이면, 그 기록이 정말 data\app.db에 들어 있는지 SQLite Viewer로 한 번 더 봅니다. 화면과 표의 값이 같아야 「SQLite에 저장되고 다시 보인다」를 근거와 함께 말할 수 있습니다. 여기서 본 표 이름과 열 이름은 2항에 그대로 씁니다.重新启动后的画面上能看到记录的话，再用 SQLite Viewer 看一次，确认这条记录真的在 data\app.db 里。画面和表里的值一样，才能有依据地说“存进了 SQLite，并且能再次看到”。在这里看到的表名和列名，原样写进第 2 项。

순서顺序
  1. 탐색기에서 data 폴더를 열고 app.db를 누른다. SQLite Viewer가 열린다.在资源管理器里打开 data 文件夹，点 app.db。SQLite Viewer 会打开。
  2. 왼쪽 목록에서 내 서비스의 표를 고른다.在左边的列表里选自己服务的表。
  3. 방금 만든 기록의 행을 찾아 화면에 보이는 값과 한 칸씩 비교한다.找到刚产生的那条记录所在的行，和画面上显示的值一格一格对比。
  4. 표 이름과 저장된 열 이름을 13_explanation.md 2항의 넷째 줄에 적는다.把表名和保存的列名写进 13_explanation.md 第 2 项的第四行。
보기만 합니다只看不动

SQLite Viewer에서 값을 고치거나 행을 지우지 않습니다. 방금 만든 기록이 안 보이면 SQLite Viewer 탭을 닫았다가 app.db를 다시 엽니다.不要在 SQLite Viewer 里改值或删行。看不到刚产生的记录时，把 SQLite Viewer 的标签关掉，再重新打开 app.db。

4. 연결 설명4. 说明连接13-2

버튼 하나가 화면 → API → SQLite → 화면으로 이어지는 길을 쓴다写下一个按钮从 画面 → API → SQLite → 画面 的路径 핵심核心

10회에는 버튼을 누르면 요청이 가고 응답이 오게 만들었고, 11회에는 그 기록이 SQLite에 남고 다시 불러와지게 만들었습니다. 이제 둘을 이어서 2항에 씁니다. 코드 문법을 풀이하는 것이 아니라, 사용자의 행동 하나가 어디를 거쳐 다시 화면에 나타나는지를 내 서비스의 말로 쓰는 것입니다.第 10 次课做到了按下按钮就发出请求、收到响应；第 11 次课做到了记录留在 SQLite 里并能重新调出来。现在把两者连起来写进第 2 项。不是讲解代码语法，而是用自己服务的话写出用户的一个操作经过哪里、又怎样回到画面上。

8. ZIP8. ZIP13-2

확인이 끝났으면 제출할 ZIP을 만듭니다. 12-2에서 연습한 것과 같은 명령입니다. 먼저 서비스를 끄는 것은, 기록 파일이 쓰이는 도중에 묶이지 않게 하기 위해서입니다. 명령은 서비스를 켜 두던 터미널에서 그대로 입력합니다.检查完后，就做要提交的 ZIP。和 12-2 练习过的是同一个命令。先关服务，是为了不在记录文件正被写入时打包。命令直接在原来运行服务的那个终端里输入。

순서顺序
  1. 13_explanation.md와 12_test_record.md를 Ctrl+S로 저장한다. 탭 옆에 ●가 없어야 한다.按 Ctrl+S 保存 13_explanation.md 和 12_test_record.md。标签旁边不能有 ●。

제출 완료 화면을 봤다면 수행평가 3과 이 과목의 수업이 모두 끝났습니다. 1회에는 AI를 어떻게 쓸지 약속을 정하는 데서 시작했고, 오늘은 내가 계획하고 AI와 함께 만든 서비스를 실행해 보이고 설명했습니다. 그 사이에 지나온 길은 이렇습니다.看到提交完成画面的话，实践考核 3 和这门课的课程就全部结束了。第 1 次课从约定怎样使用 AI 开始，今天则把自己计划、和 AI 一起做出的服务运行给人看并做了说明。中间走过的路是这样的。

지나온 길走过的路
  1. 2~5회 · Python으로 표와 그래프를 만들고, AI가 만든 결과를 원본과 대조했다.第 2~5 次课 · 用 Python 做表格和图表，把 AI 做出的结果和原始数据对照。

  3. 9회 · 사용자의 걸음으로 흐름을 펼치고, 수업에서 만들 수 있는 범위를 정했다.第 9 次课 · 按用户的脚步展开流程，定下了课上能做的范围。
  4. 10~11회 · 버튼 하나가 요청과 응답, 그리고 SQLite 기록으로 이어지게 만들었다.第 10~11 次课 · 让一个按钮接上请求与响应，再接上 SQLite 里的记录。
  5. 12~13회 · 사용자처럼 시험하고, 위험한 순서로 고치고, 설명해서 냈다.第 12~13 次课 · 像用户一样测试，按危险程度修改，写好说明交了上去。
