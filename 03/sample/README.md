# 3주차 수업 샘플

학생이 코드를 처음부터 작성하는 프로젝트가 아니라, 준비된 파일을 실행하고 결과를 읽기 위한 수업 자료다.

## 3-1 비교 결과로 판단하기

- `code/03-1_comparison.py`: 계산 결과와 비교 결과를 함께 확인한다.
- `code/03-1_boundary_values.py`: 59·60·61을 같은 기준과 비교한다.
- `code/03-1_temperature_25.py`: 현재 온도 27도와 기준 25도를 비교한다.
- `code/03-1_temperature_30.py`: 현재 온도 27도와 기준 30도를 비교한다.

학생은 두 온도 파일의 숫자와 결과를 비교하며 코드를 직접 수정하지 않는다.

## 3-2 환경과 자료구조

- `notebooks/03-2_environment_and_structures.ipynb`: 현재 Python 경로, list, dict를 차례로 확인한다.

프로젝트 폴더에서 `uv sync`를 실행한 뒤 VS Code의 Python 인터프리터와 Notebook 커널에서 이 폴더의 `.venv`를 선택한다.
