# 3주차 수업 샘플 자료

장대현중고등학교 「정보와 디지털 문해력」 **3-1·3-2 수업에서 학생이 실행할 자료**다.
학생이 처음부터 코드를 작성하는 프로젝트가 아니라, **준비된 셀을 읽고 · 예상하고 · 실행해 비교하는** 자료다.

> 이 폴더의 모든 이름과 숫자는 수업용 **가상 자료**다.
> 실제 학생 정보가 아니며 수행평가 데이터도 아니다.

## 이 폴더의 역할

3-1에서 학생은 이 폴더를 통째로 VS Code로 열고 `uv sync`를 실행한다.
그러면 `.venv`가 만들어지고, Notebook의 커널로 그것을 고른다.

**`pyproject.toml`에는 `ipykernel` 하나만 들어 있다.** 그래프·표 라이브러리는 넣지 않는다.
4-1에서 학생이 `uv add`로 직접 가져오는 경험을 해야 하는데, 미리 넣어 두면 그 장면이 성립하지 않는다.

## 3-1 자료

| 파일 | 역할 | 학생이 하는 일 |
|---|---|---|
| `notebooks/03-1_first_notebook.ipynb` | 준비 확인 → 계산과 비교 → 여섯 비교 → 경계값 | 셀을 위에서 아래로 실행 |

경계값 셀(`59 / 60 / 61`)은 실행하기 전에 결과를 예상하게 한다. 이 차시의 매듭이다.

## 3-2 자료

| 파일 | 역할 | 학생이 하는 일 |
|---|---|---|
| `notebooks/03-2_structures.ipynb` | list → 번호 → 범위 밖 오류 → dict → 나의 dict → 여러 명 | 셀을 위에서 아래로 실행 |
| `code/03-2_structures.py` | 같은 내용의 대체 경로 | Notebook을 못 열 때 `▶ Run Python File` |

`.py` 대체 파일을 두는 이유는 커널 연결이 끝나지 않은 학생이 있을 수 있기 때문이다.
Notebook을 열지 못해도 그 차시의 학습 목표는 지켜져야 한다. 3-1·3-2 각각 한 파일씩 둔다.

`scores[4]` 셀은 **오류가 나는 것이 정상이다.** 긴 오류 문장을 해석하게 하지 않고
마지막 줄의 `IndexError`와 `out of range` 두 부분만 보게 한다.
`.py` 대체 파일에서는 파일이 중간에 멈추지 않도록 같은 내용을 안내 문구로 출력한다.

## 배포 규칙 — Notebook 출력은 비운다

**두 Notebook 모두 코드 셀의 출력과 실행번호를 지워서 배포한다.**

교과서와 PPT가 여러 번 "실행하기 전에 결과를 예상해 보세요" 라고 시킨다.
출력이 남아 있으면 파일을 여는 순간 답이 보여 그 활동이 성립하지 않는다.
특히 3-1의 경계값 셀과 3-2의 `scores[4]` 셀이 그렇다.

자료를 고친 뒤에는 반드시 출력을 지우고 zip을 다시 만든다.

## 사용 범위

숫자, 문자열, `print()`, 변수, 비교연산자, list, dict까지다.

**사용하지 않는 것**: 조건문(`if`), 반복문(`for`), 함수 정의, `input()`,
list의 `append`·`remove`·`sort`·슬라이싱·`len()`, dict의 키 추가·삭제,
외부 라이브러리(pandas·matplotlib 등), CSV 읽기.

## 환경 준비

이 폴더에서 실행한다. `.venv`는 이 폴더 안에 만들어진다.

```bash
uv sync
```

VS Code에서 Notebook을 열 때 오른쪽 위 커널 선택에서 **이 폴더의 `.venv`** 를 고른다.
