1. 결과의 종류 1. 结果类型 03-1

산술연산은 값을, 비교연산은 판단을 만든다 算术产生数值，比较产生判断 

score = 72

print(score + 10)
print(score >= 60)
표현 表达式 결과 结果 종류 类型
score + 10 82 숫자 数字
score >= 60 True 조건이 맞는지 条件是否成立

비교연산은 두 값을 비교해 조건이 맞는지 알려 줍니다. 比较运算会比较两个值，告诉我们条件是否成立。

2. 기호 2. 符号 03-1

여섯 비교연산자와 경계값 六个比较运算符与边界值

기호 符号 뜻 含义 예 例 결과 结果
> 크다 大于 8 > 5 True
< 작다 小于 8 < 5 False
>= 크거나 같다 大于等于 8 >= 8 True
<= 작거나 같다 小于等于 8 <= 7 False
== 같다 等于 8 == 8 True
!= 같지 않다 不等于 8 != 5 True

=는 저장, ==는 비교입니다. ‘60점 이상’에서 정확히 60점이 포함되는지 경계값으로 확인합니다. = 是存储，== 是比较。用正好 60 分的边界值确认“60 分以上”是否包含 60。

3. 판단값 3. 判断值 03-1

True와 False는 정답·오답이 아니다 True 与 False 不是答对与答错 

age = 16
minimum_age = 14

can_join = age >= minimum_age
print(can_join)

can_join에는 True가 저장됩니다. 이는 사람이 정한 조건이 지금 값에서 맞다는 뜻이지, 현실의 결정이 무조건 옳다는 뜻은 아닙니다. can_join 中会保存 True。它只表示在人设定的条件下当前值符合，并不保证现实中的决定一定正确。

비교 결과를 사용하기 전에 무엇을 비교하는지, 단위가 같은지, 기준값은 누가 정했는지를 먼저 확인합니다. 使用比较结果前，要确认比较对象、单位是否一致，以及标准由谁制定。

4. 흐름 4. 流程 03-1

비교 결과는 다음 행동의 기준이 된다 比较结果成为下一步行动的依据 

score = 72

if score >= 60:
    print("기준을 충족했습니다.")

이번 시간에는 if 문법을 자세히 쓰지 않습니다. score >= 60이 True일 때 아래 행동이 실행된다는 흐름만 봅니다. 本课不详细学习 if 语法，只观察 score >= 60 为 True 时下面的动作会执行。

  • 이상과 초과를 구분했는가? 是否区分“以上”和“超过”？
  • 이하와 미만을 구분했는가? 是否区分“以下”和“未满”？
  • 비교하는 두 값의 단위가 같은가? 比较的两个值单位是否一致？

6. 정리 6. 小结 03-1

코드가 정확해도 기준이 틀릴 수 있다 代码正确，标准仍可能错误

이번 차시에서 남길 것 本课时要记住的
  • 비교연산은 True 또는 False를 만든다. 比较运算产生 True 或 False。
  • =는 저장, ==는 비교다. = 是存储，== 是比较。
  • 기준·단위·연산자가 틀리면 판단도 틀린다. 标准、单位或运算符错误，判断也会错误。
  • AI가 만든 비교도 사람이 기준을 확인한다. AI 生成的比较也要由人确认标准。
