1. 문제 1. 问题 03-2

모든 프로젝트가 같은 도구를 원하는 것은 아니다 不同项目需要的工具并不相同

핵심 질문 核心问题

프로젝트마다 필요한 도구가 달라질 때 어떻게 섞이지 않게 준비할까? 每个项目需要不同工具时，怎样避免混在一起？

  • 프로젝트 A는 어떤 라이브러리의 이전 버전이 필요할 수 있다. 项目 A 可能需要某个库的旧版本。
  • 프로젝트 B는 같은 라이브러리의 새 버전이 필요할 수 있다. 项目 B 可能需要同一库的新版本。
  • 한쪽을 바꾸면 잘 되던 다른 프로젝트가 멈출 수 있다. 改动一边，原本正常的另一项目可能停止。

가상환경은 별도의 컴퓨터나 보안 공간이 아니라, 프로젝트마다 사용할 Python과 라이브러리의 자리를 나누는 폴더입니다. 虚拟环境不是另一台电脑或安全空间，而是按项目区分 Python 与库位置的文件夹。

2. 비유 2. 类比 03-2

가상환경은 프로젝트 옆의 전용 도구함이다 虚拟环境像项目旁边的专用工具箱

Project A · .venv Project B · .venv
실제 항목 实际项目 도구함 비유 工具箱类比
.venv 그 프로젝트만의 도구함 该项目自己的工具箱
pyproject.toml 필요한 도구 목록 所需工具清单
uv.lock 정확한 버전 기록 精确版本记录
uv sync 목록대로 도구함 준비 按清单准备工具箱
3. 준비 3. 准备 03-2

Jupyter 확장과 uv를 설치한다 安装 Jupyter 扩展与 uv 실습 实践

VS Code 확장에서 Microsoft가 게시한 Jupyter를 설치합니다. Python 확장은 .py 실행, Jupyter 확장은 .ipynb Notebook의 셀 실행을 돕습니다. 在 VS Code 中安装 Microsoft 发布的 Jupyter 扩展。Python 扩展帮助运行 .py，Jupyter 扩展帮助逐单元运行 .ipynb。

Terminal
uv --version

uv가 없다면 uv 공식 설치 안내에서 교사가 확인한 Windows 방식을 사용합니다. 학교 PC에서 WinGet이 가능하면 아래 명령을 쓸 수 있습니다. 若没有 uv，按教师当天确认的官方 Windows 方法安装。学校电脑可用 WinGet 时可使用下列命令。

Terminal
winget install --id=astral-sh.uv -e
uv --version

설치 뒤 VS Code를 완전히 닫고 다시 열어야 새 명령을 찾을 수 있습니다. 安装后要完全关闭并重新打开 VS Code，才能找到新命令。

4. 연결 4. 连接 03-2

기록을 읽어 .venv를 준비하고 같은 환경을 고른다 读取记录准备 .venv，并选择同一环境 실습 实践

Terminal
uv sync
  • 프로젝트 폴더 전체를 VS Code로 연다. 用 VS Code 打开整个项目文件夹。
  • uv sync를 실행해 .venv와 라이브러리를 준비한다. 运行 uv sync，准备 .venv 与库。
  • Python: Select Interpreter에서 .venv가 들어간 Python을 고른다. 在 Python: Select Interpreter 中选择含 .venv 的 Python。
  • Notebook의 커널도 같은 .venv로 고른다. Notebook 内核也选择同一个 .venv。
Notebook
import sys
print(sys.executable)

학생이 기억할 행동은 ‘프로젝트 열기 → uv sync → .venv 선택’ 세 단계입니다. 学生只需记住“打开项目 → uv sync → 选择 .venv”三步。

그다음 sample/notebooks/03-2_environment_and_structures.ipynb를 열고 셀 왼쪽의 ▶를 위에서 아래로 누릅니다. 현재 Python 경로에 이 프로젝트의 .venv가 보이는지 먼저 확인합니다.然后打开 03-2_environment_and_structures.ipynb，从上到下运行单元。先确认 Python 路径中出现当前项目的 .venv。

5. 여러 값 5. 多个值 03-2

list는 순서로, dict는 이름으로 값을 묶는다 list 按顺序，dict 按名称组织值 

scores = [72, 85, 90, 68]
print(scores[0])

student = {
    "name": "민준",
    "score": 85,
    "passed": True,
}
print(student["name"])
자료구조 数据结构 값을 찾는 기준 查找依据 알맞은 예 适合的例子
list 순서와 위치(0부터) 顺序与位置（从 0 开始） 여러 날의 점수·메뉴 목록 多天分数、菜单列表
dict 이름과 의미 名称与含义 한 학생의 이름·점수·통과 여부 一名学生的姓名、分数、是否通过

추가·삭제·복잡한 반복은 아직 하지 않습니다. 모양과 역할만 구분합니다. 暂不学习添加、删除或复杂循环，只区分外形与作用。

6. 정리 6. 小结 03-2

환경을 먼저 확인한 뒤 자료를 실행한다 先确认环境，再运行数据

  • 가상환경은 별도의 가상 컴퓨터가 아니다. 虚拟环境不是另一台虚拟电脑。
  • uv sync로 프로젝트의 .venv를 준비했다. 用 uv sync 准备了项目的 .venv。
  • 인터프리터와 Notebook 커널에서 같은 .venv를 골랐다. 解释器与 Notebook 内核选择了同一 .venv。
  • list와 dict의 차이를 구분한다. 能够区分 list 与 dict。
