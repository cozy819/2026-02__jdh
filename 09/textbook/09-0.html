1. 기본 조건1. 基本条件9-0

모두 같은 표준 프로젝트 하나에서 만든다大家都在同一个标准项目里做 핵심核心

이 자료는 9~13회에 AI가 내 PRD보다 먼저 읽는 수업 조건입니다. 09 폴더의 00_course_rules.md와 내용이 같습니다. AI는 내 아이디어를 바로 코드로 만들지 않고, 먼저 이 조건 안에서 가능한지 확인합니다. 나도 같은 조건으로 AI의 답을 확인합니다.这份资料是第 9~13 次课 AI 比我的 PRD 先读的课堂条件，和 09 文件夹里的 00_course_rules.md 内容一样。AI 不会把我的点子直接做成代码，而是先确认在这些条件内能不能做。我也用同样的条件来核对 AI 的回答。

  • 9회에는 코드·화면·프로젝트 파일을 만들지 않습니다. 실제 개발은 10회부터입니다.第 9 次课不生成代码、画面和项目文件。真正的开发从第 10 次课开始。
  • 10회부터는 선생님이 나눠 주는 표준 프로젝트(Next.js) 하나에서 만듭니다. 화면과 서버를 나누지 않습니다.从第 10 次课起，在老师发的一个标准项目（Next.js）里做。画面和服务器不分开。
  • 패키지·포트·DB 위치·공개 방법은 학생이 고르지 않습니다. 표준 프로젝트에 정해져 있습니다.包、端口、数据库位置、公开方式都不由学生选，标准项目里已经定好。
  • 핵심 기능은 한 가지입니다.核心功能只有一个。
  • 모든 서비스는 핵심 기능을 쓰면 생기는 의미 있는 기록을 SQLite에 저장하고 다시 보여 줍니다. 표는 한 개로 시작해도 됩니다.每个服务都要把使用核心功能时产生的有意义的记录存进 SQLite，并再次显示出来。表从一张开始也可以。
  • 실제 개인정보와 민감한 정보를 쓰지 않습니다.不使用真实的个人信息和敏感信息。
2. 되는 것과 안 되는 것2. 能做和不能做9-0

수업에서 쓸 수 있는 기능과 만들지 않는 기능课上能用的功能和不做的功能 핵심核心

왼쪽은 표준 프로젝트 안에서 바로 만들 수 있는 기능이고, 오른쪽은 이번 수업에서 만들지 않는 기능입니다. 오른쪽 기능은 외부 계정이나 유료 키가 필요하거나, 여러 사람과 기기를 동시에 다뤄야 해서 수업 시간 안에 안전하게 만들기 어렵습니다.左边是在标准项目里马上就能做的功能，右边是这次课不做的功能。右边的功能需要外部账号或付费密钥，或者要同时处理很多人和设备，很难在课上安全地做出来。

수업에서 쓸 수 있는 기능课上能用的功能
  • 글자·숫자·날짜 입력, 항목 고르기, 버튼输入文字·数字·日期，选择项目，按钮
  • 입력 확인, 간단한 계산·분류·정렬·검색检查输入，简单的计算·分类·排序·搜索
  • 결과·안내·목록 보여 주기显示结果·提示·列表
  • SQLite에 기록 저장하고 다시 불러오기把记录存进 SQLite 再调出来
  • 선생님이 준비한 이미지·예시 자료老师准备的图片·示例资料
  • 브라우저 안의 간단한 2D 그림과 움직임浏览器里简单的 2D 图形和动画
이번 수업에서 만들지 않는 기능这次课不做的功能
  • ChatGPT·Gemini 같은 외부 AI 연결과 API 키连接 ChatGPT·Gemini 等外部 AI 和 API 密钥
  • 로그인·회원가입·비밀번호·여러 기기 동기화登录·注册·密码·多设备同步
  • 외부 DB·클라우드 저장, 결제·광고外部数据库·云存储，支付·广告
  • 이메일·문자·푸시 알림, 휴대폰 위젯邮件·短信·推送通知，手机小组件
  • 크롤링, 영상·음성 분석爬取网页，分析视频·语音
  • 실시간 채팅, 여러 사람이 동시에 하는 게임实时聊天，多人同时进行的游戏
3. 교사 확인3. 老师确认9-0

선생님 확인을 받아야 하는 기능需要老师确认的功能

어떤 기능은 무조건 안 되는 것이 아니라 선생님이 확인한 뒤에만 쓸 수 있습니다. AI는 이런 기능을 개발 계획에 바로 넣지 않고 교사 확인 필요라고만 표시합니다. 확인을 받기 전에는 그 기능이 있다고 가정하고 계획을 세우지 않습니다.有些功能不是绝对不行，而是老师确认之后才能用。AI 不会把这类功能直接写进开发计划，只标上 교사 확인 필요（需老师确认）。确认之前，不以有这个功能为前提做计划。

  • 파일 올리기(업로드)와 파일 저장上传文件与保存文件
  • 외부 공개 자료 연결连接外部公开资料
  • 핵심 기능에 꼭 필요한 추가 패키지 (예: 3D 그림 도구)核心功能必需的额外的包（例：3D 绘图工具）
  • 외부 사이트의 지도·영상 연결连接外部网站的地图·视频
「교사 확인 필요」는 「된다」가 아닙니다“需老师确认”不等于“可以”

수업 시간 안에 확인을 받지 못하면 그 기능은 작은 대안으로 바꾸거나 이번 개발 범위에서 뺍니다.课上没能确认的话，这个功能就换成小替代方案，或从这次开发范围里去掉。

4. 대안4. 替代方案9-0

어려운 기능은 결과를 지키는 작은 대안으로 바꾼다难做的功能换成能守住结果的小替代方案 핵심核心

어려운 기능을 만났을 때 몰래 다른 기능으로 바꾸거나, 작동하지 않는 기능을 된 것처럼 말하지 않습니다. 먼저 사용자가 그 기능으로 얻으려던 결과를 말하고, 수업에서 만들 수 있는 작은 대안을 찾습니다. AI 기능을 규칙이나 예시 자료로 바꿨다면 수업용 프로토타입이라고 적습니다.遇到难做的功能时，不要偷偷换成别的功能，也不要把跑不起来的功能说成做好了。先说清用户想通过它得到的结果，再找课上能做的小替代方案。把 AI 功能换成规则或示例资料的话，要写成课堂用原型。

원래 아이디어原来的点子수업에서 만들 수 있는 대안课上能做的替代方案
AI가 글이나 질문을 이해해 답한다AI 理解文字或问题并回答학생이 정한 규칙·키워드로 답을 고른다, 또는 준비한 예시 답을 보여 준다按学生定的规则·关键词选出回答，或显示准备好的示例回答
AI가 사진·영상·소리를 분석한다AI 分析照片·视频·声音사용자가 필요한 값을 직접 입력한다用户自己输入需要的值
로그인해서 내 기록을 본다登录后看自己的记录로그인 없이 한 기기에서 쓴다. 필요하면 별명만 입력한다不登录，在一台设备上用。需要的话只输入昵称
여러 기기에서 이어서 쓴다在多台设备上接着用한 기기에서 다시 켜도 기록이 남는 것까지만 한다只做到在一台设备上重新打开记录还在
알림·위젯으로 알려 준다用通知·小组件提醒첫 화면에 오늘 할 일·상태를 먼저 보여 준다首页先显示今天要做的事·状态
친구와 실시간으로 대화·대결한다和朋友实时聊天·对战한 화면에서 차례로 하거나, 남긴 기록을 목록으로 본다在一个画面里轮流进行，或以列表查看留下的记录
3D 게임3D 游戏브라우저 2D 화면에서 핵심 규칙 하나만 만들고, 판이 끝나면 기록을 남긴다在浏览器 2D 画面里只做一条核心规则，一局结束就留下记录
5. 판정5. 判定9-0

기능마다 넷 중 하나로 판정한다每个功能都判定为四种之一

9-2에서 AI는 사용자 흐름에 나오는 기능마다 아래 넷 중 하나로 판정하고 이유를 씁니다. 판정한 뒤에도 내가 확인하기 전에는 코드를 만들지 않습니다. AI가 지킬 순서는 맨 아래 상자와 같습니다.9-2 时，AI 会把用户流程里出现的每个功能判定为下面四种之一，并写出理由。判定之后，在我确认之前也不生成代码。AI 要遵守的顺序和最下面的框一样。

판정判定뜻意思
수업에서 구현 가능课上可以实现표준 프로젝트 안에서 바로 만들 수 있다.在标准项目里直接就能做。
단순화하면 구현 가능简化后可以实现목적은 남기고 범위를 줄여야 한다.保留目的，但要缩小范围。
교사 확인 필요需老师确认파일 올리기·외부 자료·추가 패키지가 필요하다.需要上传文件、外部资料或额外的包。
수업 범위에서 구현 어려움课上难以实现외부 계정·유료 키·복잡한 운영이 필요하다.需要外部账号、付费密钥或复杂的运维。
AI가 지킬 순서AI 要遵守的顺序

사용자 흐름을 먼저 이해한다 → 각 단계가 이 조건 안에서 가능한지 확인한다 → 필요한 범위 조정을 제안한다 → 학생이 흐름과 범위를 확정한 뒤에만 개발 순서를 쓴다.先理解用户流程 → 确认每一步在这些条件内能不能做 → 提出需要的范围调整 → 学生确定流程和范围之后，才写开发顺序。
