1. 준비1. 准备10-2

표준 프로젝트와 문서를 준비한다准备标准项目与文档 실습实践

  1. 교사가 배포한 표준 Next.js 프로젝트를 복사합니다.复制老师发放的标准 Next.js 项目。
  2. 규칙에 맞게 폴더 이름을 바꿉니다.按规则修改文件夹名。
  3. docs/에 수업 조건·PRD·개발 계획 문서를 넣습니다.把课程条件、PRD、开发计划放进 docs/。
  4. 교사가 제공한 명령 하나로 실행하고 기본 화면을 엽니다.用老师提供的一条命令运行，打开基本画面。
docs/ — 필수 문서docs/ — 必需文档
00_course_project_rules.md
08_assessment2_학생ID_이름.md
09_development_plan_학생ID_이름.md
기본 화면이 열리지 않으면如果基本画面打不开

코드를 수정하지 않고 교사의 복구본으로 실행 환경부터 확인합니다.不改代码，先用老师的恢复版确认运行环境。

2. 약속2. 约定10-2

내 서비스의 API 약속을 한 줄씩 확정한다逐项确定我的 API 约定 실습实践

  • 사용자의 핵심 행동用户核心行动
  • 요청 주소와 방법请求地址与方法
  • 요청에 보낼 데이터请求发送的数据
  • 성공 응답으로 받을 데이터成功响应的数据
  • 실패 응답으로 받을 안내失败响应的提示
  • 화면에 보여 줄 결과画面显示的结果
같은 기능의 공통 API가 아닙니다不是所有人共用同一功能

학생마다 만드는 서비스가 다르므로 주소와 데이터도 다를 수 있습니다. 다만 위 여섯 항목은 모두 확인합니다.每个学生的服务不同，地址与数据也可以不同，但都要确认上面六项。

3. AI 요청3. 向 AI 请求10-2

AI에게 코드보다 약속을 먼저 설명하게 한다让 AI 在代码前先说明约定 핵심核心

AI 요청문 — 아직 코드 수정 금지AI 请求文 — 暂不改代码
docs 폴더의 수업 조건, PRD와 개발 계획을 읽어 줘.
아직 코드를 수정하지 마.

핵심 사용자 행동 ___을
프로젝트 내부 API로 연결할 계획을 설명해 줘.

1. 어떤 화면 행동이 요청을 보내는지
2. 요청 주소와 GET/POST 중 방법
3. 요청에 보낼 데이터
4. 성공·실패 응답으로 받을 데이터
5. 응답 뒤 화면이 어떻게 바뀌는지
6. 수정할 파일과 각 파일의 역할

[제한]
- 하나의 Next.js 프로젝트 안의 내부 API만 사용
- 핵심 기능 하나만 연결
- DB·저장·파일 업로드·로그인·결제·외부 API 제외
- 새 패키지 추가와 프로젝트 전체 재작성 금지
코드가 먼저 나오면 멈추게 합니다如果先出代码就让它停下

“아직 수정하지 말고, 요청·응답 약속부터 쉽게 설명해 줘”라고 다시 요청합니다.再说一次：“先不要修改，请先简单说明请求·响应约定。”

4. 판단4. 判断10-2

AI의 제안을 사용자와 API 관점에서 확인한다从用户与 API 角度检查 AI 提议 핵심核心

  • 요청을 보내는 행동이 9회의 흐름과 맞는가?发请求的行动符合第 9 次课流程吗？
  • 보내는 데이터가 핵심 기능에 필요한 것뿐인가?发送的只是核心功能必需的数据吗？
  • 성공 응답이 화면에 보여 줄 결과와 맞는가?成功响应符合画面要显示的结果吗？
  • 실패 응답이 무엇을 고칠지 알려 주는가?失败响应会告诉用户改什么吗？
  • 수업에서 제외한 기능이나 패키지를 추가하지 않는가?没有加入课程排除的功能或新软件包吗？
  • 요청·응답을 내 말로 설명할 수 있는가?能用自己的话说明请求·响应吗？
모두 확인한 뒤에만 수정을 허용합니다全部确认后才允许修改

이해하지 못한 항목은 AI에게 “사용자의 행동과 화면에 보이는 결과로 다시 설명해 줘”라고 묻습니다.对不理解的项目，请 AI “用用户行动与画面结果重新说明”。

5. 연결과 관찰5. 连接与观察10-2

핵심 API를 연결하고 정상·실패 응답을 본다连接核心 API，观察成功·失败响应 실습实践

  1. AI에게 확인한 계획대로 수정하라고 합니다.让 AI 按已确认的计划修改。
  2. 교사가 안내한 방법으로 프로젝트를 실행합니다.按老师的方法运行项目。
  3. 정상 값으로 핵심 행동을 실행합니다.用正常值执行核心行动。
  4. 응답으로 받은 결과가 화면에 맞게 나타나는지 봅니다.确认响应结果是否正确显示在画面。
  5. 입력을 비우거나 잘못된 값으로 실패 응답도 확인합니다.清空输入或用错误值确认失败响应。

정상 입력과 잘못된 입력, 두 가지를 시도하며 각각 다음 세 가지를 적습니다.试正常输入与错误输入两种，各写下面三项。

  • 보낸 데이터发送的数据
  • 받은 응답收到的响应
  • 화면에 보인 것画面显示
복잡한 개발자 도구는 필수가 아닙니다不必使用复杂开发工具

Postman이나 개발자 도구를 의무로 쓰지 않습니다. 자신의 행동과 화면의 결과를 위 표에 기록하면 됩니다.不强制使用 Postman 或开发者工具，只需记录自己的行动与画面结果。

6. 수정6. 修改10-2

약속과 다른 첫 단계만 찾는다只找到第一个与约定不同的步骤 핵심核心

작은 수정 요청문最小修改请求文

현재는 ___을 했을 때 ___이 보여.

전체 프로젝트를 다시 만들지 마.

수정을 멈추고 마지막으로 정상이던 상태를 교사에게 알립니다. 프로젝트 전체를 AI에게 다시 만들게 하지 않습니다.停止修改，把最后正常的状态告诉老师。不让 AI 重做整个项目。

7. 11회 준비7. 准备第 11 次课10-2

아직 기억하지 못하는 것을 확인한다确认还不能记住的内容 실습实践

API가 성공했더라도 페이지를 새로 열거나 프로젝트를 다시 시작하면 방금 만든 기록이 사라질 수 있습니다.即使 API 成功，重新打开页面或重启项目后，刚刚的记录也可能消失。

  • 현재 잘 작동하는 요청과 응답当前正常的请求与响应
  • 새로 열었을 때 사라지는 것重新打开后消失的
  • 11회에 SQLite에 저장할 핵심 기록第 11 次课要保存到 SQLite 的核心记录
  • 저장된 기록을 다시 확인할 순간用户再次查看保存记录的时机

8. 정리8. 小结10-2

완료 확인과 활동 결과完成确认与活动结果

  • 표준 프로젝트가 실행된다.标准项目可以运行。
  • AI가 PRD·9회 계획·수업 조건을 먼저 읽었다.AI 先读了 PRD、第 9 次课计划与课程条件。
  • 핵심 사용자 행동 하나만 API로 연결했다.只把一个核心用户行动连到 API。
  • AI가 요청·응답·화면 변화를 코드보다 먼저 설명했다.AI 在代码前先说明了请求、响应与画面变化。
  • 정상 입력과 잘못된 입력의 응답을 모두 확인했다.确认了正常与错误输入的响应。
  • DB·파일 업로드·로그인·외부 API를 추가하지 않았다.没有加入 DB、文件上传、登录、外部 API。
  • 11회에 SQLite에 저장할 핵심 기록을 적었다.写下了第 11 次课要存入 SQLite 的核心记录。
10회가 끝나면第 10 次课结束时
  • 핵심 행동 하나가 화면 → 요청 → 내부 API → 응답 → 화면으로 이어진다.一个核心行动能走通画面 → 请求 → 内部 API → 响应 → 画面。
  • 아직 기억하지 못하는 문제를 11회에 SQLite로 해결한다.第 11 次课用 SQLite 解决还不能记住的问题。
다음 차시로进入下一课时

11회에는 오늘 연결한 API에 SQLite 저장과 조회를 붙이고, VS Code의 SQLite Viewer로 실제 데이터가 남았는지 확인합니다.第 11 次课会在今天的 API 上加入 SQLite 保存与查询，并用 VS Code 的 SQLite Viewer 确认数据是否真正留下。
