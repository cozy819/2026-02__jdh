# notebooks

## `00_visualization_preview.ipynb` — 2-1 완성 예시

`data/01_festival_booth_activity.csv`의 **100,000개 방문 기록**을 읽어 하나의 대시보드 화면까지 만든 완성본이다.
모든 셀이 실행되어 출력 결과가 저장된 상태이므로, 열기만 하면 화면에 결과가 보인다.

구성 순서:

1. 안내 — 이 자료가 가상 샘플이고 수행평가 데이터·정답이 아니라는 표시
2. AI에게 전달할 수 있는 요청 예시 (실제 대화 기록이 아니다)
3. 원본 CSV 확인 — 첫 몇 행, 행·열 개수, 열 이름, 비어 있는 값, 부스별·시간대별 합계
4. 대시보드 만들기 — 숫자 요약 3개와 그래프 3개를 16:9 한 화면으로 구성
5. 원본 데이터와 대조 — 화면에 그려진 값을 CSV와 하나씩 비교
6. 사람이 확인한 결과 정리

수업에서 강조할 점:

- **이 Notebook 전체를 학생이 만들어야 한다는 뜻이 아니다.** 결과의 형태를 보여 주는 자료다.
- 수행평가 1에서는 더 단순한 CSV로 **지정된 그래프 한 개**를 완성한다.
- `코드가 오류 없이 끝났다`와 `원하는 결과가 나왔다`는 다르다. 마지막 두 구간이 그 차이를 보여 준다.
