수업 화면에 사용할 **가상 CSV** 두 개가 들어 있다. 실제 학교·학생의 정보는 들어 있지 않고,
**수행평가의 실제 데이터도 아니다.** 두 파일은 목적이 다르므로 섞어 쓰지 않는다.

## `01_festival_booth_activity.csv` — 2-1 흥미 유도용

가상 학교 축제의 개별 부스 방문 기록이다. **100,000행 × 9열**.

| 열 | 뜻 |
|---|---|
| `visit_id` | 가상 방문 기록 번호 |
| `visited_at` | 방문 시각 |
| `time_slot` | 시간대 (10:00 ~ 16:00, 7개) |
| `booth` | 부스 이름 (6개) |
| `category` | 분류 (음식 / 게임 / 체험) |
| `grade` | 학년 (1 ~ 3학년) |
| `spent_won` | 가상 결제 금액(원) |
| `wait_min` | 대기 시간(분) |
| `satisfaction` | 만족도 (5점 만점) |

숫자는 무작위가 아니라 학생이 그래프에서 찾아낼 수 있는 흐름을 담아 만들었다.

- 방문 기록은 **13:00에 가장 많고** 그 앞뒤로 줄어든다.
- 방문자가 몰리는 시간대일수록 **대기 시간이 길어진다.**
- **대기 시간이 길어지면 만족도가 낮아진다.**
- 부스마다 방문 기록 수와 결제 금액의 크기가 다르다.

`notebooks/00_visualization_preview.ipynb`에서 읽는다.

## `02_subject_scores.csv` — 2-2 설명용

가상 과목 성적표다. **학생 5명 × 3과목**뿐이며, 이름은 `학생 A` ~ `학생 E`로만 적었다.

```csv
student,korean,english,math
학생 A,82,91,76
...
```

- **2-2 수업에서 이 CSV를 Python으로 읽지 않는다.** 화면에 표로 보여 주기만 한다.
- 표의 숫자는 `code/02_numbers_and_variables.py`에 **직접 적혀 있다.**
- 과목 수와 학생 수를 늘리지 않는다. 등수·석차·표준편차 같은 항목도 넣지 않는다.

두 파일 모두 UTF-8로 저장한다.
