## 남은 항목 — `02-1-08-opencode-auth.png`

**계정·결제 화면이므로 사람이 직접 찍는다.** 자동으로 대신 찍지 않았다.

### 무엇을 찍는가

현재 실제로 뜨는 **OpenCode 공식 인증 페이지**에서 다음이 보이게 한다.

- 로그인 버튼 또는 **Create API Key** 위치
- 페이지 주소가 보이는 브라우저 주소창

### 찍기 전에 지킬 것

1. **로그아웃 상태나 새 시크릿 창**에서 연다. 이것이 가장 안전하다.
2. 계정 이메일·이름·기존 키 목록·결제 정보가 보이면 찍지 말고, 가린 뒤 다시 찍는다.
3. **실제 API 키 값은 어떤 경우에도 화면에 두지 않는다.**
4. 예전 특강 자료의 화면을 흉내 내지 말고 지금 실제 화면을 쓴다.
5. 다른 캡처와 맞추려면 가로로 긴 비율(16:9 근처)로 자른다.

### 결제 정보를 요구하면

**카드나 결제 수단을 입력하지 않는다.** 그 화면에서 멈추고 어떤 화면이 나왔는지만 공유한다.
그 경우 이 한 장은 넣지 않고 본문 설명만으로 갈지 따로 정한다.

## 참고 — 캡처 화면에서 개인정보를 지우는 방법

터미널을 찍을 때는 프롬프트에 사용자 이름과 홈 폴더 경로가 그대로 나온다.
캡처 전에 터미널에서 다음을 실행하면 프롬프트가 짧아진다.

```bash
PS1='sample $ '; clear
```

opencode 화면 아래쪽에는 프로젝트의 전체 경로가 표시되므로, **그 줄은 잘라내고** 저장한다.
