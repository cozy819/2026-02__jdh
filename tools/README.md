# 교과서 인쇄 검사 도구

`.page` 하나가 인쇄 A4 한 장에 정확히 대응하는지 확인한다. 이것이 이 교과서의 기본 규격이다.

## 왜 필요한가

`.page`는 `min-height`만 걸려 있어서 **내용이 길면 그냥 늘어난다.** 화면에서는 멀쩡해 보이고
`scrollHeight > clientHeight` 같은 넘침 검사에도 걸리지 않는다. 그런데 인쇄하면 두 장으로 쪼개진다.
반드시 아래 두 검사를 쓴다.

## 쓰는 법

두 스크립트 모두 **playwright 와 크로미움이 있어야 돈다.** 선생님 컴퓨터에는 없다 —
이 검사는 Claude 세션에서 돌린다. 다른 기계에서 돌릴 일이 있으면 `CHROME_PATH` 로
크롬 실행 파일을 가리키고, 교과서 루트가 현재 폴더가 아니면 `BOOK_ROOT` 로 지정한다.

```bash
cd 수업구성/교과서_배포

node tools/pagemeasure.mjs                       # 교과서 전체. 쪽별 높이와 넘치는 쪽
node tools/pdfcheck.mjs                          # 교과서 전체. .page 수 = 인쇄 장수 인지

node tools/pdfcheck.mjs 04/textbook/04-1.html    # 한 파일만 볼 때
```

인자를 안 주면 `NN/textbook/*.html` 을 전부 본다.

## 기준

- A4 인쇄 영역은 **680 × 1002 px** (210×297mm, 여백 16mm/15mm).
- 한 쪽의 높이가 **1002px를 넘으면 인쇄 시 두 장으로 쪼개진다.**
- 여유를 두어 **950px 아래**를 목표로 한다. 2주차 02-3이 620~880px 범위로 잘 맞춰져 있다.
- `pdfcheck`의 `.page 수 = 인쇄 장수`가 최종 판정이다.

## 넘칠 때

1. **쪽을 나눈다.** `id`에 `b`를 붙여(`s2` → `s2b`) 새 `<section class="page">`를 만들고,
   `kick` 번호와 상단 목차(`#toc`)를 다시 매긴다. 2-3의 `s2b`가 선례다.
2. 나눌 때는 **의미 단위로** 끊는다. 「왜 필요한가」와 「어떻게 하는가」는 좋은 경계다.
3. **참고·주의는 쪽 아래쪽에 모은다.** 본문 → 코드 → 실행 결과 → 참고 → 주의 순서.
4. 그래도 애매하게 넘칠 때만 `.page`에 `print-tight` 클래스를 준다. 먼저 나누는 쪽을 택한다.
