# 4주차 수업 샘플

준비된 Notebook을 실행하며 라이브러리, 그래프, pandas와 DataFrame을 확인한다. 학생은 코드를 처음부터 작성하거나 값을 고치지 않는다.

- `notebooks/04-1_matplotlib_graph.ipynb`: 원본 표와 지정 막대그래프를 함께 확인한다.
- `notebooks/04-2_pandas_table.ipynb`: dict → DataFrame → 지정 그래프의 연결을 확인한다.
- `output/04-1_visitors_bar.png`: 4-1에서 저장되는 막대그래프
- `output/04-2_dataframe_bar.png`: 4-2에서 저장되는 막대그래프

## 준비

```powershell
uv sync
```

VS Code의 Python 인터프리터와 Notebook 커널에서 이 폴더의 `.venv`를 선택한다.

`uv add`는 프로젝트에 새 라이브러리를 추가하고 필요한 도구 목록을 갱신하는 명령이다. 수업 샘플에는 필요한 라이브러리가 이미 기록되어 있으므로 다시 추가할 필요는 없다.
