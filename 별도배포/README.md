# 별도 배포 자료

`교과서_배포/`의 차시 교과서와 **함께 묶지 않고 따로 전달하는 자료**다. 필요할 때 이 폴더째 압축해 배포한다.

## 1. 구성

| 파일 | 쪽 | 대상 | 언어 | 내용 |
|---|---:|---|---|---|
| `09-0.html` | 9 | **학생 · AI** | 한국어·중국어 | 9회에 AI에게 먼저 읽히는 수업 개발 조건표 |
| `09-13.html` | 24 | **교사 전용** | 한국어 | 9~13회 개발 수업 준비자료 |

> [!warning] 두 파일의 대상이 다르다
> `09-0.html`은 학생이 AI에게 전달하는 자료이므로 배포해도 된다.
> **`09-13.html`은 교사용이다.** 표준 프로젝트 구조, 복구 절차, 평가 제외 항목이 들어 있으므로 학생에게 주지 않는다.
> 학생 배포용 ZIP을 만들 때는 `09-13.html`을 빼고 압축한다.

## 2. 왜 따로 두는가

- **차시 교과서가 아니다.** `09-0`은 조건표, `09-13`은 교사 준비물이라 1~13회 목차에 넣으면 흐름이 끊긴다.
- **배포 시점이 다르다.** `09-0`은 9회 직전에, `09-13`은 학기 준비 단계에 필요하다.
- **대상이 다르다.** 위 경고 참조.

## 3. 폴더가 독립적이다

`assets/`에 `textbook.css`와 `textbook.js` **복사본**을 두었다. 이 폴더만 압축해도 그대로 열린다.

> [!important] 본편 CSS를 고치면 여기도 갱신한다
> `교과서_배포/assets/`가 원본이고 이 폴더의 것은 복사본이다. 디자인을 고친 뒤에는 반드시 다시 복사한다.
>
> ```bash
> cd 교과서_배포
> cp assets/textbook.css assets/textbook.js 별도배포/assets/
> ```

## 4. 배포하는 법

```bash
cd 교과서_배포

# 학생용 — 교사 자료를 빼고 압축
zip -r 별도배포_학생용.zip 별도배포 -x "별도배포/09-13.html" "별도배포/README.md"

# 교사용 — 전부
zip -r 별도배포_교사용.zip 별도배포
```

인쇄본이 필요하면 브라우저에서 열고 상단 `인쇄` → PDF로 저장한다. `.page` 하나가 A4 한 장이다.

## 5. 원본 설계 문서

- `교과서_설계/09-0 AI 개발 조건 - 수업에서 가능한 것과 어려운 것.md`
- `교과서_설계/09-13 교사용 개발 수업 준비자료.md`

원고를 고치면 이 두 HTML도 함께 고친다. 본편과 달리 **차시 번호가 붙지 않으므로** `교과서_배포/README.md`의 상태표에는 올라가지 않는다.

## 6. 09-13이 요구하는 후속 작업

`09-13.html`의 §10 목록은 **템플릿 제작 전에 값을 고정해야 하는 항목**이다. 아직 정해지지 않았다.

- Node.js / Next.js / React / TypeScript 버전
- 패키지 관리자와 lockfile
- 학생이 쓸 실행 명령 한 개
- Prisma·SQLite 버전과 DB 파일 위치
- 플랫폼 주소 방식(경로형 / 서브도메인형)
- 파일 업로드 허용 여부, ZIP 최대 크기
- 플랫폼 장애 시 대체 제출 위치

이 값이 정해지면 §11 준비물 관리표의 `준비 전` 항목을 갱신한다.
